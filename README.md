# Trm42 Tap

## How do I install these formulae?

`brew install trm42/tap/<formula>`

Or `brew tap trm42/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "trm42/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
